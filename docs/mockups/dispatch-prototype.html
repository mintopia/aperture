Core Principles
1. No containers — spacing is structure
Sections separated by typography size and whitespace, not bordered cards. The interface reads like a well-set document, not a grid of boxes.
2. Color = meaning, never decoration
Green means up. Red means down. Accent means action. Blue means data. The background is monochrome. Color is rare, so it's noticed. The accent hue is admin-configurable per event.
3. Dense but hierarchical
More data visible per screen. Tight spacing on data, generous spacing between sections. The eye reads top-to-bottom, not card-to-card.
4. Purpose-built, not templated
This doesn't look like "a web app." It looks like operations software — something built for a specific job by people who understand the domain.
5. Warm, not cold
Charcoal blacks with sepia warmth instead of blue-tinted slate. Admin picks the accent hue per event — tangerine default, but a Quake tournament runs red, a Minecraft evening runs lime.
